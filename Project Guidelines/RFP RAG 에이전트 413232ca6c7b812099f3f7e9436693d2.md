## 프로젝트 개요

- **미션**: B2G 입찰 컨설팅 스타트업 ‘입찰메이트’의 사내 RAG 에이전트 구축. 나라장터 등 RFP(제안요청서)에서 요구 조건·발주 기관·예산·제출 방식 등 핵심 정보를 추출·요약하고 Q&A 제공
- **데이터**: 실제 RFP 100건 (hwp, pdf) + 메타데이터
- **인프라**: GCP VM + L4 GPU, OpenAI API
- **기간**: November 9, 2026 → November 30, 2026 (3주, 5인)
- **발표**: 중간 November 17, 2026, 최종 November 30, 2026
- **API 비용 한도**: $20

## 목표

- **1차 (베이스라인)**: LangChain 에이전트 또는 LangGraph로 RAG 기능 수행
- **2차 (최종)**: 입찰 컨설팅에 필요한 기능을 도구·그래프 노드로 정의한 복합 에이전트
- **평가**: 평가 방식·지표를 팀이 직접 선정. 모든 의사결정 과정이 보고서·발표에 드러나야 함 → 「실험 로그」「의사결정 로그」에 꼭 기록

## 진행 규칙

- **협업일지**: 매일 모든 팀원이 각자 작성 (하루 마감 전)
- **데일리 스크럼** (10~15분): 어제 한 일 / 오늘 할 일 / 막히는 부분 → 「회의록」
- **태스크**: 모든 작업은 「태스크」 보드에 등록, GitHub 이슈와 링크
- **실험 기록**: 파싱·청킹·임베딩·모델·프롬프트 실험은 결과와 함께 「실험 로그」에
- **의사결정 기록**: 기술 선택과 그 이유는 「의사결정 로그」에 (보고서 근거)
- **스프린트 회고**: 금요일 KPT (Keep / Problem / Try) → 「회의록」
